# آزمایشگاه تعاملی اثر انگشت TLS (JA3 و JA4)
### TLS Fingerprint Lab — Interactive Network Security Demonstration

پروژه **TLS Fingerprint Lab** یک آزمایشگاه آموزشی تعاملی، دیداری و خودکفا است که برای ارائه‌های دانشگاهی و درس امنیت شبکه طراحی شده است. این ابزار به مدرس و دانشجو اجازه می‌دهد مفهوم اثر انگشت دیجیتال TLS (TLS Fingerprinting)، سازوکار پروتکل‌های **JA3** و **JA4**، آسیب‌پذیری‌های هرکدام در برابر تغییر ترتیب افزونه‌ها (Extension Permutation) و کاربردهای تحلیل ترافیک رمزنگاری‌شده در مراکز عملیات امنیت (SOC) را در قالب یک دموی عملی و زنده بررسی کنند.

---

## 🌟 ویژگی‌های کلیدی پروژه

1. **کاملاً آفلاین و بی‌نیاز از اینترنت:**
   - صفر وابستگی به CDN، فونت‌های خارجی، فونت‌آیکون‌های اینترنتی یا APIهای ابری.
   - دارای موتور رمزنگاری داخلی TypeScript (پیاده‌سازی مستقیم RFC 1321 MD5 و FIPS 180-4 SHA-256) جهت اجرای ۱۰۰٪ مستقل در مرورگر.
2. **رابط کاربری تیره و تخصصی (Cyber / Wireshark / SOC):**
   - زبان فارسی راست‌چین (RTL) با کنتراست تقویت‌شده مناسب برای نمایش روی ویدئوپروژکتور کلاس.
   - نمایش رشته‌های هش و فیلدهای هگز با فونت Monospace و نشانگرهای مقایسه‌ای (Diff Highlighting).
3. **انطباق ۱۰۰٪ با مستندات رسمی:**
   - **الگوریتم JA3 (Salesforce):** حذف کامل کدهای GREASE (RFC 8701)، ساخت رشته ۵ بخشی و هش MD5 منطبق بر وکتور رسمی `ada70206e40642a3e4461f35503241d5`.
   - **الگوریتم JA4 (FoxIO):** پیاده‌سازی فرمت ۳ بخشی `ja4_a_ja4_b_ja4_c`، مرتب‌سازی صعودی افزونه‌ها و سایفرها، حذف SNI (0000) و ALPN (0010) از هش افزونه‌ها و برش ۱۲ نویسه‌ای SHA-256.
4. **آزمایشگاه اصلی کلاس (JA3 vs JA4 Showdown):**
   - آزمایش زنده تغییر ترتیب Extensions؛ مشاهده بی‌درنگ تغییر هش JA3 در مقابل پایداری کامل هش JA4.
5. **تحلیلگر فایل‌های واقعی PCAP و PCAPNG:**
   - پارسر باینری اختصاصی آفلاین در پایتون و تایپ‌اسکریپت (بدون نیاز اجباری به نصب ابزارهای جانبی).
   - پشتیبانی از tshark در صورت نصب بودن در سیستم میزبان با تشخیص و گزارش خودکار وضعیت.
6. **حالت اختصاصی ارائه کلاسی (Presentation Mode):**
   - نمای متمرکز بدون حواشی اضافی با یادداشت‌های گوینده (Presenter Notes) و پشتیبانی از کلیدهای جهت‌نما.

## 🚀 راهنمای اجرای سریع (Quick Start)

پروژه به گونه‌ای طراحی شده که با یک اسکریپت ساده روی سیستم‌عامل‌های **macOS** و **Linux (Ubuntu / Debian)** اجرا شود.

### روش ۱: اجرای خودکار با یک دستور (پیشنهادی)

در ترمینال، وارد پوشه پروژه شوید و دستور زیر را اجرا کنید:

```bash
chmod +x start.sh
./start.sh
```

اسکریپت به صورت خودکار:
- وابستگی‌های بک‌اند پایتون (`venv`) و فرانت‌اند (`npm`) را در صورت نیاز آماده می‌کند.
- سرور بک‌اند FastAPI را روی پورت `3085` بالا می‌آورد.
- سرور فرانت‌اند Vite را روی پورت `3084` بالا می‌آورد.

سپس در مرورگر خود آدرس زیر را باز کنید:
👉 **[http://127.0.0.1:3084](http://127.0.0.1:3084)**

---

### روش ۲: اجرای دستی (گام‌به‌گام)

#### گام ۱: راه‌اندازی بک‌اند (FastAPI)
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 3085
```
*مستندات تعاملی Swagger API در آدرس `http://127.0.0.1:3085/docs` در دسترس خواهد بود.*

#### گام ۲: راه‌اندازی فرانت‌اند (React + Vite)
در یک پنجره جدید از ترمینال:
```bash
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 3084
```
*رابط کاربری در آدرس `http://127.0.0.1:3084` در دسترس است.*

## 📐 جزئیات فنی و قواعد الگوریتم‌ها

### ۱. الگوریتم JA3 (Salesforce)
رشته خام JA3 طبق استاندارد از ترکیب ۵ مولفه با کاما (`،`) ساخته می‌شود:
```
SSLVersion,CipherSuites,Extensions,EllipticCurves,ECPointFormats
```
- **فیلتر مقادیر GREASE:** طبق RFC 8701، مقادیر آزمایشی رزرو شده (مانند `0x0a0a`, `0x1a1a`, ... یا در مبنای ۱۰: `2570`, `6666`, ...) قبل از تولید رشته حذف می‌شوند.
- **توابع هش:** رشته نهایی با الگوریتم MD5 هش شده و رشته ۳۲ نویسه‌ای هگزادسیمال تولید می‌شود.
- **وکتور آزمون رسمی:**
  - ورودی: `769,47-53-5-10-49161-49162-49171-49172-50-56-19-4,0-10-11,23-24-25,0`
  - خروجی هش MD5: `ada70206e40642a3e4461f35503241d5`

### ۲. الگوریتم JA4 (FoxIO)
فرمت خروجی JA4 شامل ۳ بخش جدا شده با خط تیره است:
```
[JA4_a]_[JA4_b]_[JA4_c]
```
1. **بخش `JA4_a` (۱۰ نویسه خوانا):**
   - پروتکل: `t` برای TCP، `q` برای QUIC/UDP.
   - نسخه TLS: مثلاً `13` برای TLS 1.3، `12` برای TLS 1.2 یا `s3` برای SSL 3.0.
   - وضعیت SNI: حرف `d` در صورت وجود دامنه مقصد، یا `i` در صورت اتصال با آدرس IP یا غیاب SNI.
   - تعداد Cipher Suites: عدد ۲ رقمی (با صفربندی در سمت چپ).
   - تعداد Extensions: عدد ۲ رقمی (با صفربندی در سمت چپ).
   - فیلد ALPN: دو نویسه ابتدایی و انتهایی اولین پروتکل ALPN (مثلاً `h2` برای HTTP/2، `h1` برای HTTP/1.1 یا `00` در صورت غیاب).
2. **بخش `JA4_b` (۱۲ نویسه):**
   - هش SHA-256 از لیست Cipher Suiteها پس از تبدیل به هگزادسیمال ۴ رقمی، حذف مقادیر GREASE و **مرتب‌سازی صعودی**.
3. **بخش `JA4_c` (۱۲ نویسه):**
   - هش SHA-256 از لیست Extensions (مرتب شده به صورت صعودی، با حذف مقادیر GREASE و **حذف اختصاصی کدهای SNI 0000 و ALPN 0010** زیرا در بخش JA4_a منعکس شده‌اند) به علاوه الگوریتم‌های امضا (Signature Algorithms بدون مرتب‌سازی مجدد).

## 👨‍🏫 یادداشت ویژه برای استاد و ارائه‌دهنده

> **اثر انگشت یک نشانه (Indicator) است، نه هویت قطعی:**
> در تحلیل‌های امنیتی، تطابق اثر انگشت یک کلاینت با یک بدافزار شناخته‌شده به معنای اثبات ۱۰۰٪ آلودگی سیستم نیست؛ چرا که اگر یک بدافزار با کتابخانه استاندارد `requests` در پایتون نوشته شده باشد، همان اثر انگشتی را تولید می‌کند که یک اسکریپت بی‌خطر بک‌آپ‌گیری روزانه در پایتون ایجاد می‌کند! از سوی دیگر، با مکانیزم‌های مدرنی همچون **ECH (Encrypted Client Hello)**، محتویات ClientHello از دید ناظر پنهان شده و اثرانگشت‌گیری به چالش کشیده می‌شود.
